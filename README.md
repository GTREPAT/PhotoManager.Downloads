# PhotoManager.Downloads

Repositorio público destinado a distribuir los instaladores oficiales de PhotoManager.

## Última versión

Consulta las [versiones publicadas](https://github.com/GTREPAT/PhotoManager.Downloads/releases) y descarga el instalador para Windows desde los archivos adjuntos a cada release.

PhotoManager está disponible para Windows 10 y 11 de 64 bits. El instalador puede mostrar una advertencia de Windows porque actualmente no está firmado digitalmente.
