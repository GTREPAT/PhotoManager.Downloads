ILLUSTRATIVE EXAMPLE

An editorial reading of this image, not a live AI-generated result.

01 · What is in the image

A dragonfly rests on a branch. The blurred foliage separates the subject from its surroundings, while the light reveals details in its wings.

Learn to observe: start with the subject, surroundings and light before judging the photograph.

Visual observer · VisualAnalyzer
02 · How it guides your eye

The branch crosses the frame diagonally. The contrast between the insect and the soft background draws your eye to it; bright areas in the background can also attract attention.

Ask yourself: which element did you look at first, and what drew you to it?

Composition critic · CompositionCritic
03 · How it works technically

The wings show detail, with a clear difference between the subject and the blurred background. To assess fine focus and noise, inspect the original at a larger scale.

Check: use the magnifier and sharpness map to explore where the detail is concentrated.

Technical critic · TechnicalCritic
04 · What you can learn

Subject separation, the diagonal line and the lighting on the wings work together. When reviewing another photograph, notice how these relationships change with the viewpoint or a different background.

Try it in your next shot: try a different framing and compare how prominent the subject becomes.

Editorial summary of the example

Analysis with OpenAI requires an API key and incurs usage charges. A copy of the photograph is sent; assessments are advisory. Inspecting the original helps you evaluate them.

HOW TO READ A RECOMMENDATION

From “more detail” to a reasoned decision.

An editorial macro-editing example. It does not represent an applied suggestion or a before-and-after result.

THE REASON

If the insect’s detail needs more presence, consider an adjustment limited to the subject to preserve the background bokeh.

THE CHECK

Compare the eyes and wings at 100%. Also inspect edges and the background for halos or artificial texture.

THE DECISION

Reduce or remove the adjustment if it makes the image harsh. For a local adjustment, mark the area and review the assisted mask.

GET STARTED STEP BY STEP

Your OpenAI key,
made simple.

You create the key; you pay for API usage. You do not need to buy a ChatGPT subscription to follow this guide.

How to create a key and set up payment

  1. Go to the OpenAI platform

    Sign in or create an account on the OpenAI platform. Check that you are in the organisation and project you want to use.

  2. Set up API billing

    Open Billing, add a payment method and follow the instructions to buy credits where applicable. Review the amount, terms and automatic top-up settings before confirming. You can disable automatic top-ups if you prefer to buy credits manually.

    See the official prepaid billing guide. Your credit balance should not be treated as an instant spending cutoff.

  3. Create an API key

    In API keys, create a new secret key, give it a name such as PhotoManager and store it securely. Do not share or publish it. The official getting-started guide explains how to create and protect keys.

  4. Connect it to PhotoManager

    Open Configuración → API in the application and enter your key. “Configuración” is in the footer of the main screens, next to “Procesos”. Do not enter your key on this website. Check the model selected for the agents.

  5. Try one photograph and check usage

    Request an analysis from the photo actions. Review the usage recorded in PhotoManager and compare it with the OpenAI usage dashboard. Check the current API prices before analysing large batches.

ChatGPT and the API are billed separately. A ChatGPT subscription does not automatically include PhotoManager’s API usage. Read the official explanation.

Instructions checked against official documentation on 30 September 2026. Option names may change.

When to stop

An unsigned file is not necessarily safe. If your antivirus detects malware, the source does not match or the warning is different, cancel and ask for advice before proceeding. If there is no option to continue, Smart App Control or an organisation’s policy may be blocking installation: contact your administrator or us.

Get help with installation

  1. Download from the official source

    Use this page’s download button or open the official release on GitHub. Under “Assets”, choose the EXE installer, not the “Source code” files.

BEFORE YOU START

Some answers.

Does AI decide whether a photograph is good?

It provides an advisory reading with observations and reasoning. It can be wrong and does not replace your judgement. It examines a reduced copy, which is not equivalent to inspecting the original at 100%.

How do I enable analysis?

Set up your key in “Configuración > API” and request analysis from the photo actions. It uses your OpenAI account and incurs API usage charges; you can view recorded usage in the application. Read the API key and billing guide.

Which formats can I open?

JPEG, PNG, WebP, TIFF and BMP, plus RAW formats such as DNG, CR2/CR3, NEF, ARW, RAF, ORF, RW2 and PEF. RAW compatibility depends on the camera and compression. HEIC/HEIF is not currently supported reliably.

Do I need AI to use PhotoManager?

No. You can browse photos, organise folders, view metadata, assign stars and colours, and edit without an OpenAI key. You can also explore the Catalog gallery and its demo tours. Filters based on analysis genres and tags require saved results.

What is new in version 1.0.0.23?

It adds the integrated Catalog gallery, Faces dashboard, global tags, edited thumbnails, progressive RAW loading, tours with demo data and process recovery. Read the full release notes.

Is indexing a folder the same as analysing it with AI?

No. Indexing adds photographs and their data to the local catalog. “Ver contenido” can do this automatically when a folder has not yet been indexed, showing progress for each stage. OpenAI analysis is requested separately.

Does removing a folder from the catalog delete my photos?

No. “Quitar del catálogo” asks for confirmation and removes the entry and its indexes while preserving photos and PME files. “Renombrar” changes the physical folder’s name and updates its paths.

Where are Help, Processes and Settings?

“Ayuda” appears in the headers of Thumbnails, Catalog, Ver contenido, Faces and Editor. Tours use examples and can be closed with Escape. “Procesos” and “Configuración” are in the shared footer, where you can review activity, errors and recovered tasks.

Are tasks lost if I close PhotoManager?

Supported pending tasks are saved and recovered when you reopen the application. A disconnected drive or unavailable service can leave a task blocked. Pending Recycle Bin operations require renewed confirmation before continuing.

Are my photographs sent over the internet?

Viewing images and reading metadata happen locally. When you request an OpenAI analysis, a copy of the image is sent to the service. Local features using Ollama and ComfyUI process the photograph on your computer when configured with local engines.

Do analysis or editing change the originals?

The viewer opens originals read-only. Analysis is saved in a JSON file, and the editor stores adjustments in a PME recipe alongside the photograph. Thumbnails can reflect that recipe, and the viewer lets you switch between “Original / Editada”. Exporting creates the image with the adjustments applied.

How do I install or update the application?

Download and run the installer. It installs for your user account without administrator permissions. To update, close PhotoManager and run the new installer. Unsigned installers may trigger a Windows warning.

Are Luminar Neo and local AI engines included?

No. Luminar Neo is a separate application. Ollama, ComfyUI and their models require additional setup; PhotoManager includes options to help configure them.
